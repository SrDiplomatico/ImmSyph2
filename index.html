Step 2: Select Testing Algorithm Paso 2: Seleccionar Algoritmo de Prueba

Which testing algorithm will you use? ¿Qué algoritmo de prueba utilizará?

Note: Nota: • Traditional algorithm will run Non-Treponemal Test first (RPR / VDRL).
• Reverse algorithm will run Treponemal Test first (T. Pallidum Total AB with Reflex).
• Both algorithms are CDC-approved. All tests must be performed on the same blood sample. Ambos algoritmos están aprobados por los CDC. Todas las pruebas deben realizarse en la misma muestra de sangre.
